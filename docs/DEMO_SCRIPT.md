# Demo script (3:00)

Disclosed on screen: "Faults are staged on a low-voltage demo rig."

| Time | Scene | What the viewer sees |
|---|---|---|
| 0:00–0:15 | Problem | "A 'fixed' photo can lie. A leak disappears when the pump is off." Before/after photos that look identical |
| 0:15–0:35 | Product | FixVision: See it. Fix it. Verify it. One line on each Meta model's job |
| 0:35–1:20 | Real repair (F2 leak) | Voice symptom in Hindi → SAM highlights the joint → requested check → guidance with stop conditions → functional test → **Passed**, record with measured flow and joint evidence |
| 1:20–1:50 | Fake improvement | Pump switched off, leak gone → **Inconclusive / refused**: "Pump not shown running; flow not demonstrated" |
| 1:50–2:10 | Insufficient evidence | Joint hidden by hand → **Inconclusive**: "Re-record with the joint in view for 5 s" |
| 2:10–2:35 | Results | Trial table: false passes, inconclusive rate, latency, cost per job; trace view of model calls |
| 2:35–2:50 | What we built | Architecture slide: ours vs third-party; open-weight step |
| 2:50–3:00 | Close | "A system that refuses to close a repair without sufficient evidence." Repo link |

Slow steps are pre-recorded and labelled with their real speed-up factor.
